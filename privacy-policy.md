# Privacy Policy – Conscious Search

Conscious Search does not collect, transmit, or store personal information.

The extension estimates the environmental impact of searches by calculating approximate water usage and CO₂ emissions for supported search platforms. These calculations and statistics are performed locally in the user’s browser.

Data stored by the extension includes:

- Environmental impact totals (water usage and CO₂ estimates)
- Historical statistics used for charts
- User settings such as preferred measurement units
- Optional environmental impact goals set by the user

This information is stored locally using Chrome's storage.local API and is never transmitted to external servers.

Conscious Search does not collect search queries, browsing history, personal communications, or personally identifiable information.

The extension does not sell, share, or transfer user data to third parties.
